**Cache Promotion:**
Cache promotion is the process of moving data from a slower, lower-priority cache layer to a faster, higher-priority layer upon retrieval, or from the data source into the cache layers.

This `fetch_func` is responsible for retrieving the data from its original source, which could be a database (representing the conceptual L3 layer or the ultimate data source). Additionally, if a value is found in the L2 Redis cache after an L1 miss, it is promoted to the L1 memory cache to optimize future access.
