## Summary
**Handling Partial Failures:**
The `BatchProcessor` handles partial failures by isolating errors to individual batches. When a `processor_func` fails for a specific batch, the `BatchProcessor` catches the exception, records the error message, increments a `failed_count` for the items in that batch, and optionally invokes a provided `error_handler` callback. Importantly, it then continues processing the *remaining* batches without halting the entire operation. This ensures that a failure in one batch does not prevent other independent batches from being processed. The final `BatchResult` explicitly reports `processed_items`, `failed_items`, and a list of `errors`, providing a clear overview of which parts of the overall job succeeded and which failed.

Based solely on the provided code for the `BatchProcessor.process` method, at-least-once semantics are *not directly implemented* by the `BatchProcessor` itself.
