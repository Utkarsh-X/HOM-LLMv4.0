### Cache Promotion Mechanism

Cache promotion occurs when data is found in a lower-level cache or the ultimate data source and is then copied to a higher-level cache to improve future access times.

1. **Promotion from L2 to L1**:

* Finally, the `redis_value` is returned (`cache_manager.py:119`).

* As described in the miss scenario, if the `fetch_func` (representing the L3 database/source) successfully retrieves a `value`, this value is then written to both L1 and L2 caches via the `self.set` method (`cache_manager.py:125`).
